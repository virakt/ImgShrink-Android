# App Icon

The build process created a placeholder icon using the Fyne logo.

To add a custom icon:
1. Create a 512x512 PNG image named `Icon.png` in the project root
2. The icon should represent image compression (e.g., a compressed image symbol)
3. Use the moonish blue color scheme (#6478B4) for consistency
4. Rebuild the app to include the custom icon

Recommended icon design:
- Simple, recognizable symbol
- Works well at small sizes
- Matches the glassy dark theme
- Clear on both light and dark backgrounds
